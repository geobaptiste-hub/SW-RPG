# Raccord unicité des cartes au GDD : les objets COMMUNS en 2 exemplaires

## Règle GDD (vérifiée dans Données cartes.xlsx + GDD §Répartition)
- **Armes et tenues Communes : 2 cartes** (7 objets × 2 = 14 communes) ; Rare/Épique/Légendaire/Mythique : 1.
- **Alliés hors escouades : 1** ; **Escouades : 10** (déjà en place).
- Le code encode déjà ce nombre pour les poids de tirage : `CardConstants.weaponCardCount/armorCardCount` (commun ? 2 : 1) — on le réutilise comme source de vérité.

## Principe
La règle passe d'« unique par nom » à « **plafond d'exemplaires par carte** » : une carte ne peut plus être tirée quand son plafond est atteint (2 pour un commun possédé 2 fois). Faisable sans toucher à map_service ni aux modèles : seul le calcul du set « cartes indisponibles » change dans game_service.

## 1. `game_service.dart` — deux variantes du set
Remplacer `_takenCardNames` par un compteur `_cardNamesAtLimit(s, {required bool includeBoard})` :
- Compte les exemplaires **possédés** (joueurs non éliminés : équipe + réserve) — allié non-escouade max 1, escouade max 10, arme/tenue max `weaponCardCount/armorCardCount` (commun 2, sinon 1).
- Si `includeBoard` : ajoute les exemplaires **posés sur les plateaux** (tuiles de toutes les planètes, mêmes plafonds).
- Renvoie les noms dont le compte atteint le plafond.
Deux usages :
- **Tirage** (`_unavailableCardNames`, includeBoard: **true**) : jamais plus de 2 exemplaires d'un commun en existence (possédés + posés) — passé aux 3 appelants du populate (déplacement, portail, endTurn). `createNewGame` garde le set vide.
- **Garde de rencontre + purge** (`_fullyOwnedCardNames`, includeBoard: **false**) : la purge ne se déclenche que quand les exemplaires POSSÉDÉS atteignent le plafond (sinon, ranger un premier commun purgerait à tort le second encore trouvable).
`_purgeBoardCopies` et la garde « carte déjà possédée » restent inchangés (ils consomment le set).

## 2. Effets concrets
- Ranger/équiper un **commun** → le second exemplaire **reste trouvable** (c'est le raccord GDD demandé) ; quand le 2e est pris à son tour → purge des éventuels restes.
- Rare+ / alliés : comportement actuel inchangé (plafond 1).
- Escouades : inchangé (10).

## 3. Tests (`cartes_unicite_test.dart`)
- **Nouveaux** : commun en réserve (1/2) → le second exemplaire posé **reste** et reste **tirable** (populate direct + flux) ; commun possédé 2× (2 joueurs) → plus jamais tiré + purge ; 2 exemplaires posés sur le plateau, 0 possédé → le tirage n'en produit pas de 3e.
- **Adaptés** : les tests de purge existants passent sur une carte **rare** (plafond 1, sémantique inchangée) au lieu de `.first` (rareté variable).
- Suite complète : 221+ verts (le test flux Bowcaster/R2-D2 reste valide : Bowcaster est Rare, R2-D2 unique).
